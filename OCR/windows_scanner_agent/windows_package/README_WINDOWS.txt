AI-Accounts Windows Scanner Agent

Use this on the Windows PC where the scanner is connected.

ONE-TIME SETUP:
1. Install scanner driver.
2. Install NAPS2.
3. Install Python 3.
4. Create NAPS2 profile named: AI_ACCOUNTS_ADF_A5

NAPS2 profile settings:
Source: Feeder / ADF
Page size: A5
DPI: 300
Color mode: Gray
Output: PDF

INSTALL:
Double-click:
INSTALL_AI_ACCOUNTS_SCANNER.bat

START:
Double-click desktop file:
START_AI_ACCOUNTS_SCANNER.bat

TEST:
Open browser:
http://127.0.0.1:6060/health

Then open AI-Accounts Extraction page and click Start Extraction.
